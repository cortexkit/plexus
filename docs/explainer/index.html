Connector substrate

PLEXUS

One governed door between agents and every outside service. Connectors are reviewed data, not code.

The problem it exists for. An agent is a language model. If it calls GitHub directly with your token, then any confused reasoning or injected instruction can close issues, push commits, or comment as you. Plexus puts a gate in front of every outside call: what may be called, by whom, at what risk, with which credential, and with an audit row for each one.

The bet: connectors are catalog data

Most connector platforms hand-write a wrapper per vendor, which is why their app counts are armies of code. Plexus declares a vendor in a reviewed JSONC manifest — transport, auth shape, actions, risk per action — and the same engine drives all of them. Adding a vendor is a reviewed file, not a release.

What is not negotiable

  • Credentials never enter a tool argument. An agent cannot pass a secret to plexus; credential material arrives only through an out-of-band operator ceremony. The guard is asserted at the wire, not just in a unit test.
  • Authority only narrows. Four links, each a subset of the last. Overreach is refused, never clamped.
  • Every dispatch is mediated. There is no path from an agent to a vendor that skips the governance pipeline.
  • Fail closed. Missing grant, unknown action, unverified principal, unreachable decision plane — all refuse.

Narrowing by construction

The authority chain

Four links. Each must be a subset of the one before it. There is no widening operation anywhere.

LINK 1
Manifest
A reviewed file declares which actions exist at all, and the risk of each.
catalog/*.jsonc
LINK 2
Binding ticket
An operator ceremony sets a permanent ceiling — risk and action set — and carries the encrypted credential.
issue_ticket
LINK 3
Connection
Consuming the ticket fixes that ceiling onto a live connection. It is never widened afterwards.
connections connect
LINK 4
Grant
A grant authorizes specific actions inside the connection ceiling, for one principal.
admin.grant
Wildcards are expanded at mint time. A grant for * is stored as the concrete list the ceiling held on that day. So adding an action to a manifest next month cannot retroactively widen a grant minted today.

Where privileged operations live

Ticket issuance and grant minting sit on a ManagementSurface role, structurally unreachable from the MCP gateway that serves agents. The handler additionally requires Principal::Direct, because the daemon applies no principal check to management targets — so that check is load-bearing against other supervised modules, not decoration.

Honest limit. Principal::Direct means "any code running as this user", which is provenance rather than authorization. An agent with shell access can already read the vault handles at 0600 and act at a vendor without minting anything. An approval ceremony would not close this, so plexus does not ship one: while an agent can act as the operator directly, an approval gate would only be theatre. See Built & limits.

Two transports serving, a third built and unreachable

mcp_remote 15 vendors

Speaks MCP over HTTPS directly to a vendor's server. Captures and replays the mcp-session-id header, and unwraps JSON that arrives serialized inside a text content block — which is how GitHub returns everything.

rest_api 3 vendors

Hand-written REST against a declared base URL, with SSRF and path-traversal validation. Used where a vendor has no usable MCP surface.

Drift is checked, not assumed

A manifest is a claim about a remote surface at review time, and vendors change. plexus-conformance drift compares a live tools/list against each manifest and exits non-zero on mismatch — including when a vendor is merely unexamined, because a partial sweep reading as clean is the failure this check exists to prevent. It also validates that declared poll parameters actually exist in the vendor's schema.

Complete mediation

Every call, gated

RESERVE → REVALIDATE → DISPATCH. The gap between deciding and acting is where authority is re-checked.

0
Secret-input refusal

Before anything else, the frame handler rejects arguments containing credential material — recursively, including inside nested arrays. The test asserts both the refusal code and the absence of the secret bytes anywhere in the response, because an error can be returned while still echoing the secret.

1
RESERVE — the gate chain

Connection health, catalog status, a matching grant, policy effect (allow / ask-first / block), decision-plane verdict for high-risk actions, and connection resource filters. Any failure is a typed terminal denial.

2
Snapshot generations

The reservation records the exact generation of the connection, catalog, grant, and policy rows it was authorized against, with a 60-second TTL.

3
REVALIDATE — claim or abort

Claiming the reservation re-checks those generations under a fence. If the authorizing grant was revoked in the meantime, the dispatch aborts. The grant is pinned by id.

4
Credential resolution

A zeroizing payload is fetched from the vault at dispatch time. Nothing is cached, so an upstream permission change takes effect on the next call with no restart.

5
DISPATCH and record

The transport router sends it, the outcome is reported to the decision plane if governed, and an append-only audit row is written. Arguments are hashed, never stored raw.

The audit journal

Append-only, enforced by SQLite BEFORE UPDATE and BEFORE DELETE triggers rather than by convention.

What plexus provides that a shell does not. An agent with bash can reach GitHub directly, so plexus is not a containment boundary on this host. What it provides is custody and accountability: every governed call is journaled with arguments hashed, per-action risk gates apply, ask-first parks a human decision, and unattended polling works when nobody is in session. The containment boundary is the machine, and honesty about that is why the approval machinery is parked rather than shipped as theatre.
Outbound polling, no webhooks

Watches

Plexus polls vendors on a timer and collects what changed. It never exposes an inbound endpoint.

Webhooks would mean a public listener and an unauthenticated POST vector behind NAT. Outbound polling costs latency and buys the absence of an attack surface.

Five cursor strategies

sync_tokenVendor returns an opaque token naming everything since last time.Highest fidelity; few vendors offer it.

Events, and what a gap means

Deduplication is scoped to (connection, subscription, vendor_event_id, payload_hash). The last column matters: an edited item is a new version and delivers again, while identical content never re-delivers.

A gap row means coverage may have a hole: page saturation, a suspension window or a prune interval. An edit to an already-delivered item is not a gap; it delivers as an event carrying the new content.

Scheduler discipline

  • Sequential by design. One poll runs at a time; concurrency would make a wedged pass finish faster while every poll still failed.
  • Exponential backoff at cadence × 2ⁿ, capped, with a circuit breaker suspending after 5 consecutive failures.
  • Transports registered at boot before the scheduler starts, so the first pass can reach every configured vendor.
  • Liveness is reported. A drop guard flips schedulerAlive false if the task panics, because a dead scheduler otherwise looks exactly like a quiet week.
Untrusted code, next to every credential

Probes

A small author-written script, run on a schedule, to answer questions no vendor field answers.

A watch can say "this issue changed". A probe can say "the open-issue count crossed ten" — the computation between the vendor's answer and the verdict is what the script supplies. The scripts are written by a language model from a user's prose, so they are code nobody reviewed, running inside the process that holds every vendor credential. Every decision below follows from that sentence.

A WASM guest is not import-free by construction. An earlier draft claimed it was. The compiled guest imports WASI functions including fd_* and environ_*; its isolation depends on the host supplying a context with no preopened directories and no inherited environment. So the conformance test asserts the host configuration — adding a preopen fails a test rather than silently widening the sandbox.

The rules

  • One host function. Invoke a declared action on this probe's connection. No filesystem, no fetch, no spawn, no clock beyond the poll's timestamp. A test enumerates the global surface and fails if it grows.
  • The reachable action set is fixed at registration and refused again at runtime, so reading a registration tells you everything a probe can touch without reading its script.
  • A probe returns a value, never a message. The return is a declared scalar or flat struct, validated on every run. This closes an injection path: a probe's output flows into another agent's instruction channel, and free prose there would let an authored script write instructions.
  • A malformed return never retires the watch. It reports a reason code and leaves the subscription active, because a buggy script silently killing the watch it serves is the failure the feature exists to prevent.
The timeout does not bound the vendor call. Epoch interruption preempts guest execution, so while the host callback is dispatching a request nothing interrupts it. A hanging vendor request stalls the pass while the 5s budget reports nothing wrong. Whatever wires a dispatch must carry its own deadline — this is documented on the trait an implementer has to read.

Built & limits

What works, and the limits it runs under.

Shipped and running deployed

  • Complete-mediation pipeline — reserve, revalidate, dispatch, with generation-fenced reservations.
  • Four-link authority chain with expanded wildcards and permanent connection ceilings.
  • 18 reviewed manifests, two transports, live drift checking.
  • Operator ceremony — tickets, grants, revocation, and a grants listing for the app to render.
  • Trigger fleet — five cursor strategies and cross-principal event consumption.
  • Probe sandbox and registration — QuickJS-in-WASM, proven end to end against a live vendor.
  • Agent identity seam — resolves an asserted agent to a GitHub identity, refusing rather than substituting.
  • Conformance harness — per-connector fixtures, wire traces, live drift, shipped-manifest ingest tests.

Known limits, stated plainly

  • Principal::Direct is provenance, not authorization — see Authority chain.
  • The probe sandbox timeout does not bound a hanging vendor call.
  • Plexus holds no signing material and verifies no tokens; adding either is a gated decision, not a refactor.
